# v0.9.0 design: `measure_wrapped`

Status: RED slice. `measure_wrapped` in `src/layout.rs` is a stub returning 0 (every pinned count is at least 1, so every RED fails); the tests in
`tests/measure_wrapped.rs` fail by assertion until it is implemented.

Why: a consumer pushed a 52-column caption through a one-row `label()`, which clips. The fix
is `ui::text()`, which word-wraps. To size a box for wrapped text before layout, the consumer
needs the row count at a given width (ROADMAP, 0.9 LS-4 nice-to-haves: "a wrap/measure helper").

## API

```rust
pub fn measure_wrapped(text: &str, width: u16) -> u16
```

Re-exported at the crate root next to `wrap_text`. It returns the rows `text` occupies when
word-wrapped at `width` cells, exactly as `ui::text(text)` paints it.

The painter wraps `NodeKind::Text` with `wrap_text(text, wrap, rect.width)`
(`src/painter.rs`), and `ui::text()` lowers to `Node::text_wrapped(s, style,
WrapMode::WordWrap)` (`src/ui/compile.rs`). So the implementation is
`wrap_text(text, WrapMode::WordWrap, width).len()`, saturated to `u16`. A `WrapMode`
parameter would be a better long-term signature (`CharWrap` text exists), but the RED keeps
the two-argument form that matches `ui::text()`.

## Edge cases

| Input | Result | Reason |
|---|---|---|
| empty text | 1 | `wrap_text` returns one empty line, and layout sizes the node 1 row tall |
| trailing `"\n"` | counts a blank final row (`"a\n"` is 2) | `wrap_text` splits on `\n` and keeps the empty tail |
| blank line between paragraphs | 1 row | same |
| `width == 0` | one row per grapheme (`"abc"` is 3) | what `wrap_text` does at width 0; layout itself clamps to 1, but the helper follows `wrap_text` |
| wide glyph wider than `width` | one glyph per row, never split | `wrap_text` breaks on graphemes |
| more than 65535 rows | `u16::MAX` | saturate, never wrap around |

## The oracle

`red_oracle_matches_painted_rows` lays out and paints a `WordWrap` text node at width `w`
into a surface of width `w` and height 200, then counts rows up to the last non-blank one,
for a set of texts and widths 1..=60. The texts all end in a visible glyph, so a blank last
row cannot be mistaken for no row. Texts with wide glyphs are checked from width 2, because a
2-cell glyph in a 1-cell surface paints nothing. A second test pins equality with
`wrap_text(t, WordWrap, w).len()`.

## Recipe

Captions and any text that may exceed one row use `ui::text()`, never `label()`. Size boxes
with `measure_wrapped(text, inner_width)`.
