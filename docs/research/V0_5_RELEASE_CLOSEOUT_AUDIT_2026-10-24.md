## The load-bearing categorical laws for release tests

Let `S_k` be authoritative model state, `T_k` its logical tick, `E_t` a validated event at presentation frame `F_t`, and `P_v` the projection under display policy `v`.

- **Observation purity:** `P_v(S_k)` must not mutate `S_k`, and palette/terminal size changes cannot silently advance model time.
- **Interaction soundness:** the event may cause a typed command only for a live, hittable, eligible target from the **same painted layout**. A disabled occluder blocks without granting editing authority; stale pointer capture cancels with an explicit reason.
- **Partial transport:** world→raster→cell and field-index transforms preserve identity only on valid domains; clipped, degenerate and quantized cases are explicit (do not pretend that cell centers invert quantization).
- **Command causality:** offer/accept/refuse/deliver/acknowledge are distinct, bounded observable states; only an acknowledged authoritative application transition is `S_k→S_{k+1}`. Do not equate dequeue with model mutation.
- **Undo discipline:** a failed inverse with failed compensation is `RollbackFailed`, **not** a proof of recovered state.
- **Time coherence:** one cinematic master edit clock; source-media time and model-tick time are declared maps, not competing wall clocks. Intent replay at a fixed source seed yields identical canonical model/command digests under different display policies.
- **Provenance / information loss:** every synthesized/observed segment has a source/epoch/tick or appropriate explicit unknown receipt. Media legality is a distinct human provenance gate, not something a checksum can prove.

**Non-vacuity:** for each feature-film shot using an instrument, mutate exactly one source field or command and show the accepted projected pixels/digest change; invert the association and prove the trace fails. Retain a negative no-reaction/synthetic-media mode that runs on a clean CI checkout without third-party clips.
