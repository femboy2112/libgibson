## Node J

The owner, 2026-11-13: the goal was only that LibGibson can hook into such an engine as its
renderer and player. The engine and its data do not need to be in or alongside LibGibson; users
can download them themselves.

Node J is therefore met by the in-repository adapter (#299). It is `MIT OR Apache-2.0`, contains
no GPL-derived code, and is tested with an original synthetic producer: seven properties and 29
negative controls (the adapter README's "Evidence" section). Nothing GPL is linked, vendored,
shipped or published by this project. A user who builds a GPL engine on top of the adapter
produces their own GPL program; the adapter's licence permits that, and LibGibson's licence is
unaffected.

The owner's local engine prototype stays private and is not part of any release. The earlier
plan for a separate clean-room program (#381) is closed as not needed. It can be reopened if a
first-party program is wanted later.
